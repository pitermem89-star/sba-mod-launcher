# Bearite

Open-source мод-лоадер для **Super Bear Adventure** (Android, Unity).
Идея как у Geode для Geometry Dash: единый API, моды подключаются без ручного патча игры.

Статус: **этап 1** — анализ APK. Лоадер пока не написан.

> Файлов игры в репозитории быть не должно. APK загружается только в GitHub Release.

## Что нужно

Телефон, браузер и аккаунт GitHub. Больше ничего.
Совет: в браузере включите «Версия для ПК» / Desktop site, так удобнее.

## Шаг 1. Создать репозиторий

1. Откройте github.com, нажмите **+** → **New repository**.
2. Имя: `bearite`. Видимость: лучше **Private** на время анализа (см. «Приватность»).
3. Нажмите **Create repository**.

## Шаг 2. Добавить файлы

Для каждого файла: **Add file** → **Create new file**.

1. В поле имени введите `.github/workflows/inspect.yml`. Символ `/` сам создаёт папки.
2. Вставьте содержимое файла целиком.
3. Нажмите **Commit changes** → **Commit changes**.

Повторите для `README.md` и `.gitignore`.

## Шаг 3. Загрузить APK в Release

1. Откройте `https://github.com/<ваш-логин>/bearite/releases/new`.
2. В поле **Choose a tag** введите `apk-1` и выберите **Create new tag**.
3. Название: `Original APK`.
4. Внизу нажмите **Attach binaries by dropping them here or selecting them** и выберите APK в файловом менеджере телефона.
5. Дождитесь конца загрузки и нажмите **Publish release**.

Поддерживаются `.apk`, `.xapk` и `.apks`. Если игра разбита на части (split), берите `.xapk`/`.apks`.

## Шаг 4. Запустить анализ

1. Вкладка **Actions** → слева **Inspect APK** → **Run workflow**.
2. Поле `tag`: `apk-1` (пусто = последний релиз).
3. Поле `asset`: оставьте `*.apk` (для xapk впишите `*.xapk`).
4. Нажмите зелёную **Run workflow**.

## Шаг 5. Найти отчёт

1. Подождите 1–5 минут и откройте запущенный run.
2. Отчёт виден сразу на странице **Summary**. Его можно выделить и скопировать.
3. Внизу страницы, в блоке **Artifacts**:
   - `apk-report` — `report.md`, `report.json`, список библиотек и DLL;
   - `il2cpp-dump` — только для IL2CPP: `dump.cs`, `script.json`, `DummyDll`.

Пришлите мне текст отчёта из Summary. Для этапа 2 этого достаточно.

## Если что-то пошло не так

- **No release asset matched** — проверьте тег и шаблон имени файла.
- **Красный шаг** — откройте его в run, скопируйте последние строки лога и пришлите мне.
- **Il2CppDumper FAILED** — метаданные зашифрованы или библиотека защищена. Это тоже полезный результат, пришлите отчёт как есть.
- **Нет lib/** — вы загрузили split-APK. Возьмите `.xapk`/`.apks` или полный APK.

## Приватность

Артефакты содержат структуру кода игры. Держите репозиторий приватным на время анализа.
После получения отчёта удалите артефакты: открыть run → значок корзины рядом с артефактом.
Никогда не коммитьте APK в репозиторий.
